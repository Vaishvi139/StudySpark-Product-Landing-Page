# StudySpark – Product Landing Page

## Project Description
StudySpark is a fictional online learning platform designed to help college students and beginners learn new skills through online courses.

## Target Audience
College students and beginners who want to improve their knowledge and skills.

## Features
- Header with logo, navigation links, and a call-to-action button
- Hero section with heading, description, illustration, and primary button
- Three feature cards: Expert Courses, Learn Anywhere, and Track Progress
- Footer with navigation and copyright information
- Auto Layout and reusable components created in Figma
- Consistent purple and lavender color palette

## Design Choices
Purple and lavender create a modern and welcoming appearance. Clear typography, consistent spacing, and a simple layout improve readability and navigation.

## Tools Used
- Figma
- Auto Layout
- Reusable Components
- Color and Typography Styles
